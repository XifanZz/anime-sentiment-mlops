# Dataset Versioning Documentation

## Source (数据来源)
The dataset is sourced from MyAnimeList (MAL), containing anime reviews.
Downloaded from Hugging Face: `Raiser1/anime-review-mal`.

## Versions (数据版本)
- **v1 (`anime_sentiment_balanceado.csv`)**: Baseline dataset, balanced positive/negative samples (~39MB).
- **v2 (`anime_sentiment_v2.csv`)**: Improved dataset generated by `ml/make_v2.py`. We filtered out reviews shorter than 50 characters to reduce noise, and sampled 5,000 rows for faster BERT fine-tuning experiments.

## Commit Mapping (代码与数据的对应)
- v1 data is mapped to commit `52f9732` (feat(dvc): track baseline dataset with DVC).
- v2 data is mapped to the current commit (feat(ml): create and track v2 dataset).
